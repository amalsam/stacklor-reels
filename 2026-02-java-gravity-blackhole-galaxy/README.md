# Gravity, black hole and galaxy sims in plain Java

Three desktop simulations written with Java Swing and nothing else.

Browser versions: [gravity](https://labs.stacklor.com/gravity/), [black hole](https://labs.stacklor.com/blackhole/), [galaxy](https://labs.stacklor.com/galaxy/). Moved here from `java/` in [amalsam/Gravity](https://github.com/amalsam/Gravity).

## Run it

Needs a JDK (11 or newer).

```bash
javac *.java
java GravitySimulation     # N-body gravity sandbox
java BlackholeSimulation   # your mouse is a black hole that swallows particles
java GalaxySimulation      # spiral galaxy with stars in stable orbits
```
